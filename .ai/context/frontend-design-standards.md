description: Standards for creating modern, clean, maintainable, and consistent frontend UI/UX systems
---

- Prioritize clarity, consistency, and usability over visual complexity
- Prefer clean and modern interfaces with strong visual hierarchy
- Avoid visual clutter and unnecessary decorative elements
- Design for scalability and long-term maintainability
- Maintain consistent spacing, typography, sizing, and layout systems
- Use a unified design language across the application
- Prefer reusable UI primitives and shared components
- Avoid inconsistent component behavior or styling patterns
- Prefer predictable interaction patterns
- Ensure responsive behavior across common screen sizes
- Mobile responsiveness is required by default
- Prefer accessibility-first UI decisions
- Ensure sufficient contrast and readable typography
- Maintain consistent hover, focus, active, loading, and disabled states
- Avoid abrupt layout shifts and unstable UI behavior
- Use animations sparingly and purposefully
- Prefer subtle transitions over excessive motion
- Loading states should feel responsive and intentional
- Empty states should be informative and user-friendly
- Error states should clearly explain the issue and possible actions
- Prefer semantic color usage instead of arbitrary colors
- Use design tokens or centralized theme variables where possible
- Avoid hardcoded spacing, colors, border radii, or typography values
- Prefer consistent grid and layout systems
- Keep forms simple, predictable, and accessible
- Minimize cognitive load in workflows and navigation
- Prioritize readability and scanning behavior
- Avoid deeply nested UI structures
- Prefer explicit user feedback for important actions
- Optimize UX for real-world workflows, not only ideal scenarios
- Avoid trendy UI patterns that reduce usability
- Prefer stable and maintainable design systems over one-off custom solutions
- Ensure frontend implementation matches intended UX behavior consistently
- All visible text should be clear, concise, and user-oriented
- Avoid ambiguous labels, buttons, or navigation items
