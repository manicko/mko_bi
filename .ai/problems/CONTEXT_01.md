Авторизация
В качестве логина используется email пользователя.
Email является уникальным идентификатором пользователя в системе.

Отдельное поле «Имя» не требуется.
В интерфейсе в качестве отображаемого имени может использоваться часть email до символа @.

1.1. Глобальные роли пользователей

user — обычный пользователь системы;
admin — администратор системы с полным доступом (доступна панель администратора - ее пока не описываем).

1.2. Роли доступа для дашбордов
Для каждого дашборда пользователю может быть назначена одна из ролей:

viewer — доступ только на просмотр;
editor — просмотр, загрузка данных данного дашборда, удаление дашборда.
