# Реализация компонентов графиков дашборда

## Выполнено по задаче TASK_019

### Реализованные компоненты

#### 1. Модели (models/)

**user_roles.py** - Добавлены перечисления:
- `OrientationEnum` - ориентация графика (vertical/horizontal)
- `BarmodeEnum` - режим отображения столбчатых диаграмм (group/stack)
- `YoyModeEnum` - режим YoY сравнения (absolute/percent)

**data.py** - Добавлены Pydantic модели:
- `ChartData` - данные для графика (список словарей)
- `ChartConfig` - конфигурация графика (оси, метрики, ориентация и т.д.)
- `FilterState` - состояние фильтров

#### 2. Настройки (settings/app.yaml)

Добавлена секция `charts` с настройками:
- Цвета по умолчанию
- Стили YoY сравнения
- Макет по умолчанию

#### 3. Базовый класс графика (dashboards/components/charts/base.py)

`BaseChart` - абстрактный базовый класс:
- `build_traces(data)` - построение трасс
- `create_figure(data)` - создание фигуры
- `update_layout(fig)` - обновление макета

#### 4. Столбчатая диаграмма (dashboards/components/charts/bar.py)

`BarChart` - реализация столбчатой диаграммы:
- Поддержка вертикальной и горизонтальной ориентации
- Группировка и наложение (barmode)
- Несколько осей Y (secondary_y)
- Группировка по цвету
- Автоматическое выравнивание данных

#### 5. Линейный график (dashboards/components/charts/line.py)

`LineChart` - реализация линейного графика:
- Множественные линии
- Сравнение год-к-году (YoY)
- Поддержка абсолютных и процентных значений YoY
- Группировка по цвету
- Текущий год - сплошная линия, предыдущий - пунктир

#### 6. Панель фильтров (dashboards/components/filters.py)

`FilterPanel` - компонент управления фильтрами:
- Типы: select, multiselect, range, date
- Методы: добавление, удаление, обновление фильтров
- Применение фильтров к данным
- Состояние фильтров

#### 7. Макет дашборда (dashboards/components/layout.py)

`DashboardLayout` - компоновка компонентов:
- Адаптивная сетка (Row/Col)
- Фильтры сверху, графики ниже
- Динамическое добавление компонентов
- Интеграция с Bootstrap и Dash HTML

#### 8. Тесты (tests/test_chart_components.py)

57 тестов, покрывающих:
- Базовый класс графика
- Столбчатую диаграмму (включая multi-axis)
- Линейный график (включая YoY)
- Панель фильтров
- Макет дашборда
- Интеграционные тесты

### Архитектурные решения

1. **Чистый код**: малые функции, декомпозиция, PEP8
2. **Логирование**: встроено во все компоненты
3. **Настройки**: через Pydantic и YAML
4. **Enum вместо dict/list**: для всех фиксированных значений
5. **Immutable data**: данные не изменяются на месте
6. **Без pandas**: работа со списками словарей
7. **Без бизнес-логики в UI**: только визуализация

- Поддержка текущего API и моделей данных
