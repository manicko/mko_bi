## 3. Архитектурные и кодовые проблемы

### 3.1 Критические проблемы (требуют немедленного исправления)

1. **Нет очистки загруженных файлов**
   - Файлы в `data/tmp_uploads/` накапливаются бесконтрольно
   - Решение: Вызывать `cleanup_task_files()` после обработки

2. **Отсутствует Dash/Plotly приложение**
   - Нет UI для пользователей
   - Проект не соответствует заявленной функциональности
   - Решение: Создать Dash app, интегрировать с FastAPI, реализовать страницы

3. **Нет таблиц filters, processing_configs, processing_logs**
   - Нарушение требований SPEC
   - Потеря функциональности
   - Решение: Создать модели и миграции

4. **Нет GIN индекса на aggregated_data.dims**
   - Катастрофическое падение производительности при фильтрации
   - Решение: `CREATE INDEX idx_agg_dims_gin ON aggregated_data USING GIN (dims);`

5. **Hardcoded JWT секрет**
   - Утечка безопасности в репозитории
   - Решение: Убрать дефолтное значение, требовать env переменную

### 3.2 Высокоприоритетные проблемы

6. **Нет YoY расчетов**
   - Требуется по SPEC, не реализовано
   - Решение: Реализовать функцию YoY вычислений в processing

7. **Нет расчета долей/процентов**
   - Требуется по SPEC, не реализовано
   - Решение: Добавить share/percentage вычисления

8. **Нет API для filters CRUD**
   - Невозможно управлять фильтрами
   - Решение: Создать `/filters/` эндпоинты

9. **Нет API для processing_configs CRUD**
   - Невозможно настроить обработку per dashboard
   - Решение: Создать `/processing-configs/` эндпоинты

10. **Нет API для processing_logs**
    - Невозможно аудировать обработку
    - Решение: Создать `/processing-logs/` эндпоинты

### 3.3 Средние проблемы

11. **Нет миграций базы данных**
    - Ручное управление схемой
    - Риск рассинхрона БД
    - Решение: Настроить Alembic

12. **Ограниченный error handling**
    - Некоторые эндпоинты возвращают 500 вместо валидных ошибок
    - Решение: Улучшить обработку исключений

13. **Нет rate limiting на большинство эндпоинтов**
    - Уязвимость к DoS
    - Решение: Добавить slowapi или аналог

14. **CORS разрешает все origins**
    - Уязвимость в production
    - Решение: Ограничить конкретными доменами

15. **Нет health check эндпоинтов**
    - `/health` есть, но не проверяет БД
    - Решение: Расширить health check

### 3.4 Низкоприоритетные проблемы

16. **Нет Swagger документации**
    - Хотя `/docs` работает, можно улучшить

17. **Тесты не покрывают все сценарии**
    - Особенно integration тесты
    - Решение: Добавить e2e тесты

18. **Нет CI/CD конфигурации**
    - Решение: Добавить GitHub Actions/GitLab CI

19. **Нет Docker Compose для разработки**
    - Решение: Создать `docker-compose.dev.yml`

20. **Нет .env.example**
