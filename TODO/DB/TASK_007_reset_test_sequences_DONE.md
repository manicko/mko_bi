TASK: Сбросить последовательности в очистке тестовой базы данных

FILE: src/mko_bi/tests/conftest.py

GOAL: После очистки тестовой базы данных через TRUNCATE, сбросить последовательности (включая aggregated_data_id_seq) до начальных значений, чтобы обеспечить предсказуемые тестовые данные.

IMPLEMENT:
- В конftest.py, после выполнения TRUNCATE TABLE ... CASCADE для всех таблиц, добавить команду для сброса последовательности aggregated_data_id_seq и любых других последовательностей, используемых в тестах.
- Использовать SQLAlchemy text() для выполнения SQL команды ALTER SEQUENCE ... RESTART WITH 1.
- Убедиться, что сброс выполняется после каждой функции теста или после каждой сессии, в зависимости от стратегии очистки.

LOGIC:
- Текущая стратегия очистки использует TRUNCATE, который не сбрасывает последовательности, приводя к росту значений ID между тестами.
- Сброс последовательностей обеспечивает, что каждый тест начинает с ожидаемых значений ID, улучшая предсказуемость и изоляцию тестов.

CONSTRAINTS:
- Изменения должны быть сделаны только в conftest.py.
- Не должно ломать существующие тесты.
- Должно работать с текущей настройкой тестовой базы данных.

DONE:
- После каждой функции теста (или после каждой сессии, в зависимости от фикстуры) последовательность aggregated_data_id_seq сбрасывается до 1.
- Тестовые данные становятся предсказуемыми: первые вставленные записи получают ID 1, 2, 3 и т.д.
- Все существующие тесты продолжают проходить.
