## Ключевые принципы

1. **Последовательность**: Каждая задача учитывает изменения предыдущих
2. **Миграции**: Все изменения схемы только через Alembic (после Задачи 001-003)
3. **Async**: После Задачи 002-003 вся работа с БД (включая тесты) идет через asyncpg
4. **Тестирование**: Настраивается в конце (Задача 008), когда схема уже стабильна
