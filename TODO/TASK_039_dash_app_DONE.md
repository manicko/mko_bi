GOAL: Реализовать полнофункциональный веб-интерфейс для BI дашбордов с использованием Dash и Plotly

func: create_dash_app()
func: create_login_page()
func: create_dashboard_list_page()

LOGIC:

1. Создать dash_app.py:
   - Инициализация Dash приложения
   - Интеграция с FastAPI через mount
   - Настройка layout и callback-ов
2. Страница авторизации (login):
   - Форма email/пароль
   - JWT аутентификация

   - Рендеринг графиков через Plotly
   - Панель фильтров
   - Применение фильтров ко всем графикам
5. Рендеринг графиков:
   - Поддержка bar, line, pie, table
   - Multi-axis графики
   - YoY сравнение (если данные есть)

- Использовать существующие компоненты из dashboards/components/

- Фильтры должны применяться на backend (через API)

- Адаптивный дизайн

DONE:

- Есть страница логина
